# Decision Records - Core Requirements (Community Edition)
# These packages are required for the Community Edition
#
# Every line is an exact pin, including the packages that are only installed
# because another package needs them. An unpinned SQLAlchemy (pulled in by
# Flask-SQLAlchemy) is what broke production on 2026-11-21: a fresh image build
# resolved a new major line with a different PostgreSQL driver.
#
# Updating pins (do it deliberately, one pull request at a time):
#   1. Change the version on the line you want to move. If the new version needs
#      a newer or additional dependency, pip fails the install and names it;
#      change or add that line in the "Installed by the packages above" section.
#   2. In a clean Python 3.11 virtualenv (the image interpreter):
#        pip install -r requirements.txt pytest pytest-cov && pip check
#        pip freeze    # every package listed must have a line in this file
#      (pytest, pytest-cov and their own dependencies are the only exceptions).
#   3. Run the test suite: python -m pytest tests/ -q --tb=short
#   4. Open a pull request. CI builds the image from this file and boots it
#      against both SQLite and PostgreSQL before anything can be published.
# tests/test_requirements_pins.py fails when a line is not an exact pin.
